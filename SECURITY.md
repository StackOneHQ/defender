# Security policy

## Reporting a vulnerability

Please **do not** open public GitHub issues for security reports. Report privately in one of these ways:

- [GitHub private vulnerability reporting](https://github.com/StackOneHQ/defender/security/advisories/new)
- Email **security@stackone.com**

Please include:

- The affected version of `@stackone/defender`.
- A description of the issue.
- Steps to reproduce or a proof of concept.

We aim to acknowledge reports within 3 business days.

## Supported versions

Only the latest minor release on [npm](https://www.npmjs.com/package/@stackone/defender) receives security fixes.
